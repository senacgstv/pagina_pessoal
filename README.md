|---|---|---|
| 02 | Semântica | `header`, `nav`, `main`, `section`, `article`, `footer` |

## Estrutura

```
index.html
style.css
img/
  perfil.svg   (troque pela sua foto: img/perfil.jpg e altere o src no HTML)
```

## Como publicar no GitHub Pages

1. Crie um repositório **público** no GitHub.
2. Clique em **Add file → Upload files** e envie `index.html`, `style.css` e a pasta `img`.
3. Vá em **Settings → Pages**.
4. Em **Branch**, escolha `main` e a pasta `/ (root)` e clique em **Save**.
5. Em alguns minutos o site estará em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Para usar como modelo

- Troque os textos pelos seus dados profissionais.
- Troque a imagem em `img/` por uma foto sua (ou com licença de uso).
- Personalize as cores no início do `style.css`.
- **Não publique** CPF, endereço, telefone pessoal ou dados de outras pessoas (LGPD).
